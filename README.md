# OmniTrade — Sürümler

Bu sayfada **OmniTrade** kurulum dosyaları yayımlanır.

**İndirme:** sağdaki **Releases** bölümünden en son sürümü açın ve `OmniTrade-Kurulum-x.y.z.exe` dosyasını indirin.

- Kurulum yönetici izni gerektirmez; önceki sürümün üzerine kurulur.
- Ayarlarınız, verileriniz ve lisansınız korunur.
- OmniTrade yeni sürüm çıktığında kendisi haber verir (*Yardım → Güncellemeleri denetle*).
- Uygulama lisansla çalışır. Lisans ve destek için satıcınızla iletişime geçin.
